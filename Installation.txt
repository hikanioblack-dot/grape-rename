Grape Rename 1.1.2 (build 12)

Установка

Требуется macOS Tahoe 26 или новее и Mac с Apple Silicon.

1. Перетащите Grape Rename.app в Applications (Программы).
2. Запустите приложение из Программ. При обновлении замените предыдущую копию.
3. После установки извлеките диск Grape Rename в Finder.

Сборка имеет ad-hoc подпись, пока без Developer ID и нотариального заверения Apple.
Если macOS заблокировала запуск, нажмите «Готово», откройте Системные настройки →
Конфиденциальность и безопасность и разрешите Grape Rename кнопкой «Всё равно открыть».
Официальная инструкция: https://support.apple.com/ru-ru/102445

Язык интерфейса выбирается автоматически по настройкам macOS.
Выберите файлы кнопкой или перетащите из Finder. При выборе папки берутся файлы
непосредственно в ней, без вложенных папок. Перетаскивание в открытый список
добавляет файлы к выбранным.

Три вида: компактные строки, список с миниатюрами и сетка. Справа — предпросмотр
и метаданные; панель можно скрыть или показать. Command-I показывает эту панель.
Для Quick Look выделите файл и нажмите пробел; стрелки переключают файлы,
повторный пробел закрывает просмотр.

Даты изменения и содержимое файлов сохраняются при переименовании.
История и шаблоны сохраняются после перезапуска. «Отменить» / Command-Z
возвращает последнее переименование; более ранние отменяются в обратном порядке.
EXIF-названия используют DateTimeOriginal. Без EXIF дата не добавляется.

Инструменты доступны в одноимённом верхнем меню: «Найти и изменить медиафайлы» (точные дубликаты и похожие фото),
«Поиск текста на медиафайлах» (поддерживаемые изображения). Перенос в Корзину требует подтверждения;
восстановление выполняется Finder, а не отменой переименования.

Installation

Requires macOS Tahoe 26 or later and a Mac with Apple Silicon.

1. Drag Grape Rename.app into Applications.
2. Launch from Applications. Replace the previous copy when updating.
3. Eject the Grape Rename disk in Finder after installation.

The build has an ad-hoc signature, without Developer ID signing or Apple notarization yet.
If macOS blocks opening, click Done, open System Settings → Privacy & Security,
and allow Grape Rename with Open Anyway.
Official instructions: https://support.apple.com/en-us/102445

The interface language follows your macOS settings automatically.
Choose files with the button or drag them from Finder. Choosing a folder loads files
directly inside it, without subfolders. Dropping onto an existing list adds files
to the current selection.

Three views: compact rows, a thumbnail list and a grid. The right sidebar shows
previews and metadata; it can be hidden or shown. Command-I reveals the sidebar.
For Quick Look, select a file and press Space; arrow keys switch files,
and pressing Space again closes the preview.

Renaming preserves file modification dates and contents.
History and presets survive app restarts. Undo / Command-Z restores the last rename;
earlier operations must be undone in reverse order.
EXIF naming uses DateTimeOriginal. Without EXIF, no date is added.

The Tools menu provides Find and Modify Media Files (exact duplicates and similar photos)
and Find Text in Media Files (supported images).
Moving files to Trash requires confirmation; restore them in Finder,
not with rename undo.

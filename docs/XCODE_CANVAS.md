# Xcode и SwiftUI Canvas

Canvas входит в полный Xcode; Command Line Tools для него недостаточно. Установите Xcode из App Store, откройте его и завершите первоначальную настройку. Для проекта нужен SDK macOS 26 или новее.

1. Откройте `Grape Rename.xcodeproj` в корне проекта.
2. Выберите схему **Grape Rename Canvas**, устройство **My Mac**.
3. Откройте `CanvasPreviews.swift` в навигаторе слева.
4. Включите **Editor → Canvas**. Если превью приостановлено, нажмите **Resume**.
5. Доступны два примера: список синтетических файлов и пустое окно. Тексты и расположение основного окна находятся в `ContentView.swift`, правой панели — в `FileInspector.swift`.

Canvas показывает результат изменений SwiftUI-кода и позволяет взаимодействовать с элементами в Live mode. Это не свободный графический редактор: порядок, отступы и размеры обычно меняются в коде. Selectable mode помогает найти код выбранного элемента.

Превью используют временные синтетические файлы и отдельную историю в системной временной папке `GrapeRenameCanvas`. Запуск через схему Xcode создаёт отдельное приложение **Grape Rename Canvas**, с отдельным bundle ID и историей в каталоге сборки Xcode. Выбранные вручную реальные файлы при запуске приложения остаются реальными: действия с ними работают как обычно.

Проект Xcode ссылается на существующие исходники: сохранённая правка меняет общий checkout. Не редактируйте один файл одновременно с другим чатом. Новые Swift-файлы нужно добавлять в target Xcode. Скрипт `build.sh` и публичная версия приложения не менялись; Xcode-схема предназначена для локальной работы, а не выпуска DMG.

Проверено 15 октября 2026 года в Xcode 27.0 (27A266a): проект открылся, автоматическая сборка Canvas завершилась, оба примера отобразились в Live mode. Полный экспортированный снимок примера с файлами визуально проверен. При переключении в Selectable Xcode показал «Cannot use previews in this file / app may have crashed»; возврат в Live восстановил отображение. Причина этой ошибки не установлена, для текущей работы используйте Live. При узкой панели окно требует прокрутки; подгонка масштаба пока не настроена.

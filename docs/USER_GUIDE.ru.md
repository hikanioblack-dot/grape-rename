# Grape Rename 1.1.2

Нативная программа для пакетного переименования файлов на macOS Tahoe 26 и новее, Apple Silicon.

Версия доступна в меню «Справка → Версия Grape Rename», а также в «Grape Rename → О Grape Rename». Оба пункта открывают системное окно с иконкой, версией и номером сборки. Формат версии — `1.0.x`, где `x` совпадает с номером выпускаемой сборки; текущая сборка — 11. Номера берутся из Info.plist.

## Использование

Установите приложение из `Grape-Rename.dmg`: перетащите `Grape Rename.app` на ссылку Applications. В центральной области основного окна выберите файлы или папку либо перетащите их из Finder. При выборе папки загружаются обычные видимые файлы непосредственно внутри неё; вложенные папки и символические ссылки пропускаются. Перетаскивание в открытый список добавляет новые файлы, исключая повторные пути.

В левой панели задайте общее название, разделитель, начальный номер (по умолчанию 1) и число цифр (по умолчанию 4). Пустое общее название даёт имена `0001.txt`, `0002.pdf` и так далее. Опция «Оставить исходное имя» даёт, например, `Отпуск_0001_IMG_1234.jpg`. Расширения файлов сохраняются.

Сортируйте по имени, дате изменения, дате создания, размеру или расширению. Стрелка меняет направление. Для ручного порядка перетаскивайте строки либо выделите строку и нажимайте стрелки внизу списка. В компактном списке и списке с миниатюрами фиолетовая линия показывает точное место вставки: верхняя половина строки вставляет перед ней, нижняя — после. Новые имена всегда соответствуют порядку сверху вниз. Правой кнопкой можно убрать файл из списка или показать его в Finder.

В строках отображаются миниатюры через Quick Look. Если системная миниатюра недоступна, текстовые форматы получают миниатюру текста, остальные — метку расширения. Для быстрого просмотра выделите строку и нажмите пробел. Стрелки в окне просмотра переключают файлы, повторный пробел закрывает окно. Также доступны двойной щелчок и кнопка с глазом в панели. При вводе в текстовые поля пробел вводится как обычный символ.

Нажмите «Переименовать». Кнопка «Отменить» в верхней панели или ⌘Z возвращает имена последнего переименования, включая операции до перезапуска приложения. В истории можно посмотреть все изменения. Отмена идёт в обратном порядке: сначала последняя операция, затем предыдущая. Файлы проверяются по inode, размеру, дате создания и дате изменения. Если файл перемещён или изменён, операция не выполняется. ⌘O выбирает файлы; ⇧⌘O выбирает папку; ⌘I показывает правую панель предпросмотра и метаданных.

Сохранённые шаблоны включают префикс, разделитель, параметры нумерации, исходное имя, поиск/замену и EXIF. Их можно сохранять, обновлять, удалять и выбирать повторно. Поиск и замена выполняются буквально в исходном имени, не меняя расширение. Нумерацию можно отключить для простой замены текста.

В сетке размер миниатюр регулируется. Порядок идёт слева направо, затем сверху вниз. В списке — сверху вниз. Ручной порядок доступен в обоих видах.

Для EXIF используется DateTimeOriginal, без подмены датой изменения. Форматы даты фиксированы, сохраняется местное время съёмки из EXIF. Фото без EXIF не получают дату, при сортировке они идут после датированных фото. Метаданные доступны только для чтения: общие свойства файла, свойства изображения, EXIF/TIFF/GPS при наличии и сведения PDF.

Язык интерфейса выбирается автоматически по настройкам macOS. История и шаблоны сохраняются локально в `~/Library/Application Support/Grape Rename/state.json`. Незавершённые операции записываются перед переименованием; при запуске завершённая операция попадает в историю, частичная восстанавливает исходные имена.

## Инструменты: дубликаты и похожие фотографии

В верхнем меню **Инструменты → Найти и изменить медиафайлы…** доступны режимы точных дубликатов и похожих фотографий. По умолчанию проверяются файлы из основного списка; в окне поиска можно выбрать другие файлы или папки. Для папок есть опция обхода вложенных папок. Скрытые файлы и символические ссылки пропускаются; несколько жёстких ссылок на один файл учитываются один раз.

**Точные дубликаты:** сначала сравнивается размер, затем потоково вычисляется SHA-256, после чего совпадения подтверждаются сравнением байтов. Имена, расширения и даты могут различаться.

**Похожие фотографии:** используются визуальный хеш изображения и Apple Vision. Можно выбрать строгое, сбалансированное или более широкое сходство. Этот режим помогает найти уменьшенные, пересжатые и похожие кадры, но не подтверждает одинаковое содержимое. Каждый файл сравнивается с первым изображением своей группы; автоматически удалять похожие фото нельзя.

Поиск выполняется локально в фоновом режиме, показывает ход работы и поддерживает остановку. Недоступные или повреждённые файлы перечисляются отдельно. В каждой группе один файл отмечен «Оставить»; сохраняемый файл можно поменять. Изначально ничего не выбрано. В режиме точных копий нажмите **«В Корзину все копии…»**: приложение выберет все файлы, кроме отмеченных «Оставить», и запросит подтверждение с количеством файлов. Для удаления отдельных файлов отметьте их галочками и нажмите **«Выбранное в Корзину…»**.

**Убрать из набора** исключает выбранные файлы из переименования, сохраняя их на диске. **В Корзину** запрашивает подтверждение и повторно проверяет, что файлы не изменились после поиска. Восстановление из Корзины выполняется в Finder; отмена переименования не возвращает файлы из Корзины. Показанный размер — сумма размеров выбранных файлов, а не гарантированный объём освобождённого места.

Основное окно открывается сразу. Префикс, нумерация и пример остаются на виду; шаблоны, поиск и замена и параметры EXIF находятся в сворачиваемых разделах **Дополнительно** внизу левой панели.

## Даты и защита

Программа меняет имя файла внутри исходной папки системным вызовом переименования. Она не переписывает содержимое. До операции проверяются изменения файлов и конфликты имён. Существующие файлы не перезаписываются. Обмен именами поддерживается через временные имена с последующим восстановлением при ошибке. После операции проверяются дата изменения с наносекундами, дата создания, размер и inode.

Дата изменения **файлов** сохраняется. Дата изменения родительской папки и системное время изменения метаданных (ctime) могут меняться при переименовании — это штатное поведение macOS.

## Поиск текста на изображениях

**Инструменты → Поиск текста на медиафайлах…** сканирует выбранные изображения или папки локально через Apple Vision. Метаданные не нужны. Для многостраничных и анимированных изображений анализируется первая страница/кадр. Нераспознанные и повреждённые файлы перечисляются отдельно.

Фильтры **С текстом**, **Много текста**, **Текст не обнаружен** и **Все изображения** работают без повторного сканирования. Для «Много текста» можно задать минимальное количество символов (без пробелов) и строк. Поиск слова или фразы не учитывает регистр. Справа доступны предпросмотр, распознанный текст и его копирование.

Наличие текста не доказывает, что изображение — скриншот. Фото документа тоже содержит текст, а мелкие или размытые надписи могут не распознаться. «Текст не обнаружен» не означает гарантированное отсутствие надписей.

Отметьте файлы галочками. Основная кнопка **Выбранное в Корзину…** удаляет только отмеченные файлы; копирование и перемещение находятся в меню **Действия…**. Совпадающие имена в папке назначения не перезаписываются. **Действия → Все результаты фильтра в Корзину…** действует только на результаты текущего фильтра и текстового запроса, с подтверждением количества файлов. В отличие от дубликатов, сохраняемой копии здесь нет: удаляются сами найденные изображения. Перед действиями приложение проверяет, что файлы не изменились. Восстановление — через Корзину Finder; история переименований не отменяет перемещение и удаление.

Поиск выполняется в фоне с остановкой. Опциональный локальный кэш содержит распознанный текст; его можно отключить или удалить кнопкой **Очистить кэш**. Файлы и текст не отправляются на сервер. Сканирование не меняет содержимое и дату изменения изображений.

## Сборка

Нужны Command Line Tools с Swift 6.3 и SDK macOS 26. В Terminal:

```sh
zsh build.sh
```

Скрипт создаёт приложение, ZIP, DMG и контрольную сумму в dist/, подписывает приложение локальной ad-hoc подписью и запускает тесты. Исходники доступны целиком. Сборка не использует сторонние библиотеки, сеть или телеметрию. Это локальная сборка для Apple Silicon, без Developer ID и нотариального заверения Apple для распространения на чужих компьютерах. DMG содержит приложение, ссылку Applications и инструкцию. Готовый DMG доступен в GitHub Releases.

## Проверки

Встроенный `--self-test` проверяет переименование 8 файлов, сохранность байтов и метаданных, отмену, обмен имён, отказ при конфликте и защиту от изменения файла после выбора. Также проверяются смешанный импорт файлов и папок, исключение дублей, скрытых файлов, ссылок и вложенных папок, сортировка, ручной порядок и шаблон названия.

Для проверки используйте новые синтетические примеры: `--make-fixtures PATH`, `--make-duplicate-fixtures PATH` или `--make-text-fixtures PATH`. Они включают изображения с EXIF и без него, документы, медиа и картинки с текстом. Генераторы не перезаписывают существующую папку; личные файлы для проверки не нужны.

## Обновление интерфейса

Шапка содержит только название папки в одну строку, с сокращением длинного имени и подсказкой полного названия. Меню добавления имеет текстовую кнопку. Доступны три вида: компактный список без миниатюр (строка 24 pt), список с миниатюрами и сетка. Метаданные перенесены в правую боковую панель вместе с встроенным Quick Look. Панель обновляется при выборе и переименовании файла, её можно скрывать. Просмотр по пробелу остаётся отдельным полноразмерным окном. Фото, PDF и медиа используют нативный предпросмотр.

# Редактируемые макеты интерфейса

Файл: [Grape Rename — Интерфейс macOS](https://www.figma.com/design/hxiARdcKm6MaDLleVKl4hA).

Это статические приближённые макеты текущего интерфейса для ручных экспериментов. Тексты и блоки редактируются отдельно; связанные элементы используют auto-layout и локальные компоненты. Приложение из Figma автоматически не обновляется. Inter согласован пользователем только для макета; системный шрифт приложения не менялся. Данные и изображения синтетические, кроме настоящей иконки приложения.

## Верхняя строка

[Восемь меню и их подпункты](https://www.figma.com/design/hxiARdcKm6MaDLleVKl4hA?node-id=8-837): Grape Rename, Файл, Правка, Вид, Инструменты, Файлы, Окно, Справка. Вынесены также подменю служб, автозаполнения и размещения окон.

[Меню внутри окон](https://www.figma.com/design/hxiARdcKm6MaDLleVKl4hA?node-id=8-838): добавление, контекстное меню файла, сортировка, выбор набора для поиска, действия OCR, фильтр OCR, шаблоны, формат EXIF-даты, число цифр, сходство, виды списка и назначение кнопок toolbar.

Меню приложения сверены с App.swift; стандартные меню — через UI запущенного Grape Rename. Состав/доступность системных пунктов зависит от macOS, фокуса и состояния приложения. Системное меню Apple не относится к меню Grape Rename и отдельно не воспроизводилось.

## Проверка и границы

После построения проверены размеры и отсутствие переполнения в обрезаемых контейнерах на трёх страницах, отсутствующих шрифтов нет. Просмотрены снимки основных окон, меню, результатов трёх инструментов, OCR-плотности, прогресса, компактного/пустого окна, дополнительных разделов, метаданных, подтверждения удаления, выбора файлов, Quick Look и «О приложении». Исправлены схлопнувшиеся auto-layout меню, высота кнопки «Готово» в истории, соответствие имён/индикатора вида в сетке, цвет «Оставить» и опасных действий.

Лимит вызовов Figma MCP на Starter остановил несколько последних повторных снимков (история, шаблон, сетка); структурная проверка соответствующих страниц прошла. Это ограничение автоматизации, а не свидетельство потери созданных макетов. Стеклянные материалы, изображения и стандартные системные панели упрощены; вариант тёмный, русский. Макеты не являются интерактивной реализацией файловых действий и не покрывают все комбинации динамических метаданных, ошибок и системных состояний.

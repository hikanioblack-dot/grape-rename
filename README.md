# Аккуратные названия. Ваш порядок.

**Grape Rename** — нативное приложение для пакетного переименования файлов на macOS. Выберите файлы, расставьте их в нужном порядке, посмотрите будущие имена и переименуйте весь набор одним нажатием.

Мы хотим, чтобы вы попробовали Grape Rename и оценили, насколько удобнее становится работа с файлами. Фотографии, сканы, документы и материалы проекта проще хранить с понятными названиями и последовательной нумерацией.

![Список файлов, будущие имена, предпросмотр и метаданные](docs/assets/app-screenshot.png)

## Почему это удобно

| Задача | Что делает Grape Rename |
| --- | --- |
| Навести порядок в десятках файлов | Применяет общее название и нумерацию от `0001` в вашем порядке. |
| Сначала увидеть результат | Показывает исходное и будущее имя рядом до переименования. |
| Расставить фотографии | Предлагает крупные миниатюры, сетку, сортировку и ручное перетаскивание. |
| Сохранить исходные даты | Меняет имена без переписывания содержимого и сохраняет дату изменения самих файлов. |
| Вернуться к прежним именам | Хранит историю с отменой даже после перезапуска. |
| Повторять одну и ту же задачу | Сохраняет настройки в шаблон для повторного использования. |

## Что уже умеет приложение

- Выбор файлов или папки через Finder и добавление перетаскиванием.
- Префикс, разделитель, исходное имя, начальный номер и число цифр; нумерацию можно отключить.
- Сортировка по имени, типу, размеру, дате создания, изменения или съёмки из EXIF.
- Ручной порядок и линия места вставки в компактном списке и списке с миниатюрами.
- Три вида: тонкие строки, список с миниатюрами и сетка с регулируемым размером.
- Поиск и замена текста с настройкой учёта регистра.
- Названия по дате съёмки из EXIF; для файлов без EXIF дата не подставляется.
- Быстрый просмотр по **пробелу**, переход стрелками и предпросмотр в правой панели.
- Просмотр метаданных: даты, размеры изображения, камера, EXIF и свойства других поддерживаемых форматов.
- Сохранённые шаблоны, история и отмена **⌘Z**.
- Проверка конфликтов имён и защита от перезаписи существующих файлов.
- Русский и английский интерфейс по системному языку.

## Скачать и установить

**Текущий выпуск: 1.0.7, сборка 7.** Требуются macOS Tahoe 26+ и Mac с Apple Silicon.

1. [Скачайте Grape-Rename.dmg](https://github.com/hikanioblack-dot/grape-rename/releases/latest/download/Grape-Rename.dmg).
2. Откройте DMG и перетащите **Grape Rename.app** в **Applications / Программы**.
3. Запустите приложение из Программ. При обновлении замените предыдущую копию.

DMG скачивается бесплатно, без регистрации. В релизе доступен `SHA256SUMS.txt` для проверки файла.

Текущая сборка использует локальную ad-hoc подпись, пока без Developer ID и нотариального заверения Apple. macOS может показать предупреждение о проверке разработчика. Подписанные и нотариально заверенные релизы входят в планы развития.

## Исходники и сборка

Swift, SwiftUI, AppKit и Quick Look. Сторонних библиотек и телеметрии нет; история и шаблоны хранятся локально.

Нужны macOS 26+ и Command Line Tools со Swift 6.3 и SDK macOS 26:

```sh
zsh build.sh
```

Скрипт создаёт приложение, ZIP, DMG и контрольную сумму в `dist/`, подписывает приложение локально и запускает проверки на русском и английском. Проверяются сохранность байтов и временных меток, отмена после перезапуска, конфликты имён, импорт, сортировка, EXIF и восстановление прерванных операций.

[Подробная инструкция](docs/USER_GUIDE.ru.md) · [История версий](CHANGELOG.md)

Дата изменения родительской папки и системное время изменения метаданных `ctime` могут меняться при переименовании. Сохраняется дата изменения самого файла.
